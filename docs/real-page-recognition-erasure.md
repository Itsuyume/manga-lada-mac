# 실제 페이지에서 검증한 글자 인식과 제거 · 0.2.50

작은 효과음의 회색 획, 한 번에 읽을 때 섞이는 영어 설명문, 원문 획을 덜 지우는 문제를 같은 원본에서 재현했다. 원본 파일은 수정하지 않는다. 아래 수치는 두 페이지에 대한 검사이며 책 전체의 누락률이나 번역 의미 정확도를 증명하지 않는다.

## 모듈 경계

- `detection_refinement.py`: 기존 CTD의 상세 영역을 영어 OCR 검색 창으로 정리한다. 검출 사각형 자체는 삭제 허가가 아니다.
- `VisionOCRService` / `VisionRegionRecognition`: 원본에서 영역을 잘라 작은 글자를 확대해 읽고, 좌표를 전체 페이지로 되돌린다. 원본은 그대로 두며 빈 읽기로 기존 결과를 버리지 않는다. 겹치는 조각을 정리한다.
- `english_regions.py`: 확인된 글줄의 획을 선택하고 같은 검출 문단에 속한 줄을 묶는다. 글자 끝은 확인된 픽셀을 근거로 문단 창에서 보완한다. 연결된 그림과 읽지 못한 글자를 임의로 지우지 않는다.
- `lettering_strokes.py` / `lettering_recovery.py`: 얇고 회색인 획에도 분할 위치를 만든다. 분리한 획의 OCR이 원문과 같을 때만 채택한다. 검출기의 효과음 분류 점수만으로 문구 종류를 확정하지 않는다. 말풍선 밖에서 확인된 글자를 손·옷의 흰 윤곽에 배치하지 않는다.
- `TranslateGemmaPageTranslator`: 12곳을 넘는 페이지는 같은 모델에 작은 묶음으로 요청한다. 사용자 메시지 형식을 유지하면서 JSON 개수·번호·한국어를 검증한다. 선택하지 않은 문구와 검수 정보를 유지한다. 실패한 묶음은 부분 성공으로 반환하지 않는다. 구조화된 응답에서도 기존 번호 응답과 동일하게 원문 종류 또는 기본 대사 종류를 유지한다.
- 렌더러: 작은 영어 말풍선·얇은 설명문은 해당 공간에 맞춰 크기를 계산한다. 같은 비용의 줄바꿈은 정해진 순서로 선택해 재열기 때 위치가 달라지지 않는다. 직접 넣은 줄바꿈과 크기 지정은 우선한다.

## 실제 입력과 검증 범위

| 입력 | 크기 | 확인한 결과 |
|---|---:|---|
| 일본어 흑백 페이지 | 684 × 1080 | 기존 대사 9곳과 빠졌던 `キィ…` 1곳을 확인. 한국어 저장 및 캐시 재열기 검사 |
| 영어 컬러 고전 만화 | 1740 × 2376 | 말풍선 9곳의 주요 문구와 위치를 확인. 긴 설명문을 포함한 페이지 저장 및 캐시 재열기 검사 |

일본어 효과음 복구는 **일본어 글자 인식 → 장식 글자 OCR · 추가 검출 시험 적용**(Hayai + 검출기 + EfficientSAM)에서 검증했다. 기본 만화 OCR이나 정밀 획 분리 모드가 이 페이지의 작은 효과음을 똑같이 복구한다고 주장하지 않는다. 다른 설정에서 만든 이전 완성본은 새 설정만 저장해도 덮어쓰지 않으므로 새 번역을 시작해야 한다.

영어 검증의 주요 문구 검사는 위치별 앵커 검사다. 모든 철자나 번역의 의미가 맞다는 검사가 아니다. 상단의 큰 글자는 광학 후보가 서로 다를 때 검수 대상으로 원본을 유지한다. 신뢰도 숫자를 정확도처럼 쓰지 않는다.

삭제 흔적은 원문과 제거 이미지를 같은 크기에서 대조했다. 확인된 원문 획 안의 남은 어두운 픽셀 수를 기록하며, 이 수치에 들어가지 않는 미인식 글자·테두리·질감은 별도 시각 검수 대상이다. 삭제 마스크 밖의 변경 여부와 원본 파일 해시도 확인했다.

## 재현과 검사

개인 원본·검증 이미지·절대 사용자 경로·모델 파일은 저장소에 올리지 않는다. 개인 검증 폴더에는 원본 해시, 수정 전후 PNG, 주석 manifest와 실행 결과를 함께 둔다. 기존 `--real-regression` 명령을 사용하며 기대 문구의 선택적 `bounds`는 페이지 내 정규화 좌표다. 검사 실패 시 저장 PNG와 캐시 차이 자료를 남긴다.

```sh
swift build --explicit-target-dependency-import-check error
swift run MangaLadaCoreChecks
swift run MangaLadaVisionChecks
swift run MangaLadaWorkflowChecks --cache-migration
swift run MangaLadaBallonsChecks --session-lifetime
swift run MangaLadaRenderingChecks
python3 scripts/check_detection_refinement.py
python3 scripts/check_lettering_strokes.py
python3 scripts/check_english_regions.py
python3 scripts/check_architecture.py
swiftlint lint --strict
```

기존 CI는 이 행동 검사와 경계 검사를 실행한다. 새 검사에는 회색·얇은 획, 배경 덩어리 거부, 작은 마침표·프레임 보존, 원본 보류, 문단의 겹친 OCR 높이, 좌표·빈 입력·취소·개수 제한, 번역 묶음 실패와 검수 보존, 반복 식자의 줄바꿈 안정성이 포함된다.

## 남은 한계

흐린 제목, 작은 인쇄 글자의 일부 철자, 패널 선에 붙은 글자, 질감 배경의 복원은 여전히 검수가 필요하다. 컬러 페이지의 원문 일부가 남아 있는 것을 확인했다. 새로운 영역·마스크·폰트가 맞는 것과 자연스러운 번역·존대·인물 관계가 맞는 것은 각각 검토해야 한다. 수백 장 처리 품질과 다른 만화·다른 모델의 품질은 이 두 페이지의 결과로 일반화하지 않는다.
